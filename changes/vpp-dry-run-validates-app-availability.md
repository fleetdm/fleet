- `fleetctl gitops --dry-run` now reports `requested app not available on vpp account` when an `app_store_id` under `software.app_store_apps` has no license on the fleet's VPP location, the same error the real apply returns. Previously the dry run returned success before checking Apple's asset list, so a wrong or unlicensed App Store ID passed CI and failed the apply part-way through, which could leave fleets without their App Store apps.
