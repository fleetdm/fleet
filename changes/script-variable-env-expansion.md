- Fleet now provides host script variables (such as `$FLEET_VAR_HOST_UUID` and `$FLEET_VAR_HOST_END_USER_IDP_DEPARTMENT`) to scripts and to software installer, post-install, and uninstall scripts through the execution environment. Shell scripts that reference these variables continue to work unchanged. Scripts that use a non-shell interpreter should read the corresponding `FLEET_VAR_*` environment variable directly.
