- Windows user-scoped configuration profiles (`./User/...`) are now held until a user signs in, instead of failing during setup. On hosts enrolled by a user (Autopilot, or joining Microsoft Entra ID during setup), these profiles stay "Pending" through OOBE and are delivered automatically at first sign-in. On hosts enrolled without a user, they now report "Failed" with an explanation instead of retrying a delivery that cannot succeed.
