- The GitOps repository template written by `fleetctl generate-gitops` now verifies, before running `fleetctl gitops`, that every Apple App Store app declared in the YAML is available on the VPP account, and fails the workflow with the app's name and App Store link when one is not. Previously a wrong or unlicensed `app_store_id` passed the pull request and failed the real apply part-way through, which could leave fleets without their App Store apps.
