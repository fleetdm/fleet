How this is measured

Check-in: the last time each computer's agent talked to Fleet. This covers every computer, including ones that stopped checking in long ago, so you can find and retire them.

Network path (macOS): from the DEX - Network experience - VPN gate report. "VPN tunnel" means the default route goes through a tunnel interface. "Direct" means the primary interface is up and carrying traffic. "Disconnected" means neither.

Wi-Fi (macOS): from the DEX - Network experience - Wi-Fi signal quality report, which runs every 10 minutes. Signal strength (RSSI) is excellent at -50 dBm or better, good to -65, fair to -75, poor to -85, and unusable below that. Macs on Ethernet, and Macs that withhold Wi-Fi details from location services, don't count as on Wi-Fi.

Weak: a fair, poor, or unusable signal. It's "most days" when it was weak on or more of the last 7 days with a reading.

Signal-to-noise: signal strength minus background noise. 25 dB or more is good, and under 15 dB is degraded even when the signal looks strong.

Band: 2.4 GHz is slower and more crowded than 5 or 6 GHz. Recent macOS versions hide the band from apps without location access, so it can read "unknown."
