How this is measured

Who's counted: computers that checked in within the last days. A source is fresh on a computer when it reported within the last days. A computer that hasn't checked in that recently counts only against Fleet check-in, since no other source can be fresh while it's offline.

Sources: Fleet's own data (check-in, host details, software inventory, and policies) exists on every computer. Each DEX report counts only for the platforms it runs on, and only once it's added to Fleet. A report Fleet clipped at its 1,000-row limit is marked as clipped.

Coverage by area: the share of fresh readings across the area's sources and the computers that should report them.

Security posture: disk encryption comes from Fleet (FileVault, BitLocker, or LUKS). The rest comes from the DEX - System experience - Security posture report on macOS, and the Windows Security Center, Secure Boot, and TPM reports on Windows. "No data" means the report hasn't run on that computer.

Fleet agent: the newest version is the one on the stable channel of Fleet's update server (updates.fleetdm.com), checked on each run. When the update server can't be reached, it's the highest version at least two computers run, so a lone test build doesn't set the bar.

Restart overdue: up for days or more without a restart, which usually means updates are waiting.
