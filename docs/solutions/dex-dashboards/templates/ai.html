How this is measured

Source: fleetd's ai_tools table, read by the report every hour. It finds AI desktop apps, command-line agents, editor plugins, browser extensions, MCP servers, live connections to AI services, and agent instruction files. It needs fleetd 1.59.0 or later. Computers that haven't checked in for days are left out.

Active: a product counts as active on a computer when the report saw it running or connected to an AI service, or when Fleet's software inventory shows its app was opened. The report runs hourly, so a tool used briefly between runs can be missed. Activity history starts .

Products: a desktop app, command-line agent, editor plugin, or browser extension from the same product counts once per computer. "How it runs" lists each way it's installed. MCP servers and instruction files are counted on their own.

Risk findings: the table's own risk flags, such as an agent started with an auto-approve flag or a credential in an MCP config. Severity is this dashboard's judgment of how much each one exposes.

Policy: decisions and the posture are saved with this dashboard and every change is logged with who made it and when. Only people who can edit the dashboard can change them. Fleet enforces them through the policies you copy from "Enforce it in Fleet."

Privacy: the dashboard never shows command lines, launch arguments, environment values, or usernames. File paths start at ~, so they don't include a username.
