How this is measured

Results: each computer's latest result for every policy that applies to it, from Fleet's Get host. "No result" means the policy hasn't run on that computer yet, for example right after it was added.

Who's counted: macOS, Windows, and Linux computers that checked in to Fleet in the last 30 days and have at least one policy.

Past days: each run saves every policy's counts for the day, and the last run of a day wins. Fleet doesn't keep past results, so history starts the day this dashboard started, and a day without a run shows the last run before it. Lists of failing computers show for the latest run only.

Pass rate: passing results out of passing and failing results. Computers with no result yet aren't counted.

Passing every policy: a computer with at least one passing result and no failing ones.

Charts: each policy gets one bar that adds up to 100% of its computers, so you can compare policies down the list. Pie charts can't be compared that way.
