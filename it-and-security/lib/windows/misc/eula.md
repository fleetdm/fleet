## Hey there, Fleetie 👋

This computer is managed with Fleet. Yes, we use our own product. Here's the short version of what that means.

### What IT can see 👀

- Hardware, operating system, and installed software
- Security settings like disk encryption, firewall, and screen lock
- Which user accounts sign in to this computer
- Rough location, based on your IP address

### What IT can't see 🙈

- Keystrokes or mouse movements
- Your webcam, mic, or screen

Curious about the details? Visit fleetdm.com/better.

### What IT can do 🛠️

- Install apps, settings, and updates
- Run scripts to fix things
- Lock or erase this computer if it's lost or stolen
- Pause access to company apps until a failing check is fixed

### What we ask of you 🙏

- Install updates when prompted.
- Lock your screen when you step away.
- Don't let anyone else use this computer. Screen share instead.
- Keep passwords in 1Password and sensitive data off USB drives.

### Lost it? Something seem off? 🚨

Post in #help-it right away. Minutes count.
